# 🌩️ AWS Cloudformation

> A multi-phase Infrastructure as Code (IaC) project using AWS Cloudformation to build a scalable, multi-tier architecture — including networking, compute, load balancing, and change management.

---

## 🚀 Overview

This project showcases a progressive infrastructure deployment strategy using modular Cloudformation templates. Each phase builds on the previous one and concludes with a production-style environment. It also demonstrates how to apply safe infrastructure updates using Change Sets.

- **Template 1**: Creates foundational networking components — including VPC, subnet, route table, and internet gateway.
- **Template 2**: Provisions a public EC2 web server with security groups and user data to install Apache automatically.
- **Template 2 (Change Set)**: Performs a safe, zero-downtime update to upgrade the EC2 instance type using a Change Set.
- **Template 3**: Deploys a multi-AZ, production-grade environment with two EC2 instances behind an Application Load Balancer (ALB).
